Core Fundamentals

What FloorGuard Is & How It Works

FloorGuard removes discretionary price concessions by baking enforceable economic minimums into smart contracts on Ethereum.

Feature Enforced by Protocol Behavior & Boundaries
Direct Market Listing Enforced Atomic execution on FloorGuardDirectMarket. Reverts if price < effective floor.
Seaport 1.6 Zone Enforced Restricted orders naming FloorGuardSeaportZone validate USDC gross sum before and after fill.
Owner Peer-to-Peer Gifts Allowed Wallet-to-wallet transfers initiated by the NFT owner directly (non-operators) succeed without fees.
Unrestricted Market Orders Blocked Unrestricted Seaport or marketplace orders bypass the zone; the NFT validator fails the transfer.
Marketplace Escrow Risk Zero Risk The direct market never holds buyer USDC and has no sweep or withdrawal function.
⚠️
Non-Protected Paths: Unrestricted Seaport orders, marketplaces without adapter support (e.g. Magic Eden), and off-chain agreements paired with owner gifts are outside automated enforcement. Collections must register their contract with FloorGuardTransferValidator for complete coverage.
System Topology

Contract Graph & Separation of Concerns

Price policy calculations are decoupled from marketplace execution adapters. Below are the 8 key contracts that form the protocol core:

FloorGuardCore Engine

Stores collection floor policies, per-token overrides, and calculates effectiveFloor.

  • Pinned immutable USDC token address
  • Enforces NonDecreasing and Fixed invariants
  • Cannot be upgraded or redirected
FloorGuardDirectMarket Marketplace

Atomic USDC market for 1-of-1 NFT listings. Charges gross floor price directly to buyer.

  • Zero escrow custody; instant settlement
  • Pulls exact USDC to seller, royalty, & fee
  • Sellers can cancel immediately even if paused
FloorGuardSeaportZone Hook Zone

Restricted zone hook conforming to OpenSea / Seaport 1.6 specification.

  • Validates authorizeOrder & validateOrder
  • Verifies total consideration ≥ effective floor
  • Authorizes OpenSea conduit for final transfer
FloorGuardTransferValidator Guard

Validates NFT transfers via transient storage (Cancun EIP-1153) during sale execution.

  • Authorizations expire in the same transaction
  • Allows owner-initiated wallet transfers (gifts)
  • Blocks unapproved marketplace operators
FloorGuardNFT Founding ERC-721

The 69-token founding collection bound permanently to FloorGuardTransferValidator.

  • Tokens #1 through #69 (strict cap)
  • Initial floor: 100,000 USDC
  • ERC-2981 royalty capped at 10%
FloorGuardRegistry Registry

Maintains approved marketplace adapters, verified collection status, and permissions.

  • Collections opt-in to specific adapters
  • Global adapters require timelock approval
  • verified flag for ecosystem indexing
FloorGuardGovernance Admin Scheduler

Two-step ownable contract managing timelock interactions and emergency pauses.

  • Guardian can execute emergency pauses instantly
  • Unpausing strictly requires 48-hour timelock
  • Designed for eventual Gnosis Safe ownership
FloorGuardTimelock Timelock 48h

OpenZeppelin TimelockController with a non-reducible 48-hour minimum execution window.

  • All administrative changes must queue for 48h
  • Community observers can audit queued calls
  • Execution is open to any caller once matured
Developer Guide

Smart Contract API & Integration Calls

Integrate with FloorGuard directly using Solidity or JavaScript/TypeScript libraries (viem, ethers.js). 

// Query the required minimum floor in USDC (base units: 6 decimals)
import { ethers } from "ethers";

const CORE_ABI = [
  "function effectiveFloor(address collection, uint256 tokenId) external view returns (uint256)",
  "function collectionFloor(address collection) external view returns (uint256)",
  "function tokenFloorOverride(address collection, uint256 tokenId) external view returns (uint256)"
];

async function getFloor(coreContractAddress, collectionAddress, tokenId) {
  const provider = new ethers.JsonRpcProvider(process.env.RPC_URL);
  const core = new ethers.Contract(coreContractAddress, CORE_ABI, provider);

  const rawFloor = await core.effectiveFloor(collectionAddress, tokenId);
  const usdcAmount = ethers.formatUnits(rawFloor, 6);

  console.log(`Token #${tokenId} effective floor: $${usdcAmount} USDC (${rawFloor.toString()} units)`);
  return rawFloor;
}
// Step 1: Approve the FloorGuardDirectMarket to handle your NFT
// Step 2: Call list() with a price at or above effectiveFloor
const MARKET_ABI = [
  "function list(address collection, uint256 tokenId, uint256 price, uint256 expiry) external returns (uint256 id)"
];

async function listNft(marketAddress, collectionAddress, tokenId, priceUsdc, daysValid) {
  const signer = await provider.getSigner();
  
  // Approve NFT first
  const nft = new ethers.Contract(collectionAddress, ["function approve(address to, uint256 id) external"], signer);
  await (await nft.approve(marketAddress, tokenId)).wait();

  // Convert price (e.g. 100,000 USDC -> 100_000_000_000)
  const priceBaseUnits = ethers.parseUnits(priceUsdc.toString(), 6);
  const expiry = Math.floor(Date.now() / 1000) + (daysValid * 86400);

  const market = new ethers.Contract(marketAddress, MARKET_ABI, signer);
  const tx = await market.list(collectionAddress, tokenId, priceBaseUnits, expiry);
  const receipt = await tx.wait();
  
  console.log("Listing successful! TX:", receipt.hash);
}
// Step 1: Approve DirectMarket to spend buyer USDC
// Step 2: Call buy(listingId)
async function buyNft(marketAddress, usdcAddress, listingId, priceBaseUnits) {
  const signer = await provider.getSigner();

  // Approve USDC
  const usdc = new ethers.Contract(usdcAddress, ["function approve(address spender, uint256 amount) external returns (bool)"], signer);
  await (await usdc.approve(marketAddress, priceBaseUnits)).wait();

  // Execute atomic purchase
  const market = new ethers.Contract(marketAddress, ["function buy(uint256 id) external"], signer);
  const tx = await market.buy(listingId);
  const receipt = await tx.wait();

  console.log("NFT acquired! Transfer verified by FloorGuardTransferValidator.");
}

Seaport 1.6 Zone & OpenSea Compatibility

How FloorGuard enforces floors on Seaport protocol orders without custody or proprietary wrappers.

Order Component Supported Specification Validation & Rejection Rules
Order Type OrderType.RESTRICTED Unrestricted orders do not trigger the zone and are rejected by the NFT contract.
Offer Item Exactly 1 resolved ERC-721 token ERC-1155, bundles, and criteria-based wildcard offers revert immediately.
Consideration Currency Pinned Circle USDC only ETH, WETH, or unpinned stablecoins revert. Consideration sum must meet floor.

Execution Hooks authorizeOrder & validateOrder Pre-transfer checks set transient storage; post-transfer checks confirm received gross USDC.
Decentralization & Safety

Governance Lifecycle & Security Invariants

Strict role boundaries protect users, creators, and buyers against administrative overreach or compromise.

48-Hour Timelock Delayed

All sensitive updates require a 48-hour execution delay:

  • Raising the founding collection floor
  • Lowering GovernanceAdjustable floors
  • Changing market fees (capped at 10%)
  • Approving new marketplace adapters
  • Unpausing sales paths
Guardian Pause Immediate

Emergency controls for security incidents:

  • Guardian can pause DirectMarket and Seaport Zone instantly
  • Cannot unpause (requires 48h timelock)
  • Cannot transfer NFTs or seize funds
  • Sellers can still cancel listings during pause
Immutable Boundaries Permanent

Guarantees that no admin, multisig, or timelock can alter:

  • Cannot lower the founding 100,000 USDC floor
  • Cannot seize or burn minted NFTs
  • Cannot extract USDC from market (no balance held)
  • Cannot bypass 48-hour minimum timelock delay
