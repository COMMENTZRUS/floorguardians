A Hard Floor for Ethereum NFTs, Settled in USDC

FloorGuard is an Ethereum protocol that enforces guaranteed minimum pricing right in the smart contract. If a sale doesn't meet the floor in pinned Circle USDC, the transaction simply reverts. Non-upgradeable contracts, zero marketplace custody, and 48-hour timelocks ensure that neither market panics nor rogue admins can drop the floor.

Design Principles

How FloorGuard Actually Works

Most NFT floors are just gentleman's agreements subject to market panic and undercutting. FloorGuard makes the floor an on-chain enforcement rule.

Sale Path How It Behaves Enforcement Mechanism
Direct Market Sale Enforced 100% atomic execution on FloorGuardDirectMarket. Pulls exact USDC from buyer to seller. Reverts if listing is below floor.
Seaport 1.6 Zone Enforced Restricted orders naming FloorGuardSeaportZone verify consideration sum before and after fulfillment.
Owner Gifts & Inheritance Allowed Direct peer-to-peer wallet transfers where msg.sender == owner succeed freely with zero fee or restriction.
Unrestricted Market Orders Blocked Orders that skip the zone produce no transient authorization. When the marketplace conduit calls transferFrom, the NFT contract reverts.
Marketplace Escrow Risk Zero Risk The marketplace contract never holds tokens or balances. It has no sweep or withdraw function. There are no pool funds to hack.
💡
A Gift is a Gift, a Sale is a Sale: FloorGuard allows owners to transfer their NFTs to another wallet, a vault, or a friend without paying USDC. But when a marketplace operator attempts to move the token on behalf of a user, the transfer validator requires proof of a verified sale paying at least the floor.
System Architecture

The Eight Core Contracts

FloorGuard cleanly separates price policy from marketplace adapters. Every contract has a strict, auditable boundary.

FloorGuardCore Engine

Stores collection policies, per-token overrides, and calculates the live effectiveFloor.

  • Pinned to Circle's verified USDC token
  • Enforces non-decreasing price rules
  • Immutable address; cannot be upgraded
FloorGuardDirectMarket Marketplace

The native atomic market. Buyers pay the exact USDC listing price, which is instantly routed.

  • Zero escrow custody; instant settlement
  • Directly pays seller, royalty, and fee
  • Sellers can cancel immediately, even during pauses
FloorGuardSeaportZone Hook Zone

Restricted zone contract conforming to OpenSea's Seaport 1.6 protocol specification.

  • Executes authorizeOrder & validateOrder
  • Validates consideration sum ≥ floor
  • Authorizes OpenSea conduit for transfer
FloorGuardTransferValidator Security Guard

Validates NFT transfers via Ethereum Cancun transient storage (EIP-1153).

  • Authorizations evaporate after transaction end
  • Permits owner peer-to-peer gifts
  • Rejects unapproved marketplace operators
FloorGuardNFT Founding ERC-721

The 69-piece founding collection permanently wired to FloorGuardTransferValidator.

  • Strictly capped at 69 tokens (no extra mints)
  • Burns permanently disabled
  • ERC-2981 royalty capped at 10%
FloorGuardRegistry Registry

Maintains approved marketplace adapters, verified collection status, and permissions.

  • Collections opt-in to specific adapters
  • Global adapters require timelock approval
  • Immutable binding to FloorGuardCore
FloorGuardGovernance Scheduler

Two-step ownable controller managing timelock interactions and emergency pauses.

  • Guardian can pause markets immediately
  • Unpausing strictly requires 48h timelock
  • Direct path to future Gnosis Safe multisig
FloorGuardTimelock Timelock 48h

Enforces a non-reducible 48-hour delay on all privileged administrative operations.

  • Every sensitive change is public for 48 hours
  • Community has ample time to audit changes
  • Execution is open to any caller once matured
OpenSea Deep Dive

OpenSea & Seaport 1.6: The Practical Reality

How FloorGuard integrates with OpenSea and why normal website listings fail without custom zone configuration.

⚠️
Important for Sellers on OpenSea: OpenSea’s default website listing form generates unrestricted orders with no zone. Because an unrestricted order never calls FloorGuardSeaportZone, no sale authorization is written to transient storage. If a buyer tries to purchase a standard OpenSea listing, the transaction will revert!

Integration Guide

Developer Reference & Code Snippets

Interact with FloorGuard smart contracts using ethers.js, viem, or Solidity. 

// Read the current effective floor price for a collection token
import { ethers } from "ethers";

const CORE_ABI = [
  "function effectiveFloor(address collection, uint256 tokenId) external view returns (uint256)",
  "function collectionFloor(address collection) external view returns (uint256)"
];

async function checkPriceFloor(coreAddress, collectionAddress, tokenId) {
  const provider = new ethers.JsonRpcProvider(process.env.RPC_URL);
  const core = new ethers.Contract(coreAddress, CORE_ABI, provider);

  const rawFloor = await core.effectiveFloor(collectionAddress, tokenId);
  const usdcAmount = ethers.formatUnits(rawFloor, 6);

  console.log(`Token #${tokenId} Floor: $${usdcAmount} USDC`);
  return rawFloor;
}
// Approve the DirectMarket contract, then list at or above the floor
const MARKET_ABI = [
  "function list(address collection, uint256 tokenId, uint256 price, uint256 expiry) external returns (uint256 id)"
];

async function createListing(marketAddress, collectionAddress, tokenId, priceUsdc, daysValid) {
  const signer = await provider.getSigner();

  // 1. Approve NFT
  const nft = new ethers.Contract(collectionAddress, ["function approve(address to, uint256 id) external"], signer);
  await (await nft.approve(marketAddress, tokenId)).wait();

  // 2. Submit listing (USDC has 6 decimals)
  const priceBaseUnits = ethers.parseUnits(priceUsdc.toString(), 6);
  const expiry = Math.floor(Date.now() / 1000) + (daysValid * 86400);

  const market = new ethers.Contract(marketAddress, MARKET_ABI, signer);
  const tx = await market.list(collectionAddress, tokenId, priceBaseUnits, expiry);
  await tx.wait();
  console.log("Listing live on FloorGuard Direct Market!");
}
// Approve USDC spending, then execute atomic purchase
async function executePurchase(marketAddress, usdcAddress, listingId, priceBaseUnits) {
  const signer = await provider.getSigner();

  // 1. Approve USDC
  const usdc = new ethers.Contract(usdcAddress, ["function approve(address spender, uint256 amount) external returns (bool)"], signer);
  await (await usdc.approve(marketAddress, priceBaseUnits)).wait();

  // 2. Execute atomic buy
  const market = new ethers.Contract(marketAddress, ["function buy(uint256 id) external"], signer);
  const tx = await market.buy(listingId);
  await tx.wait();
  console.log("Purchase complete! NFT transferred and floor verified.");
}

Security & Control

Governance Boundaries & Emergency Controls

No administrator should have absolute power over your assets. FloorGuard's security model guarantees that rogue keys cannot lower the floor or steal funds.

48-Hour Timelock Delayed

All sensitive protocol operations must queue for 48 hours before execution:

  • Raising the founding collection floor
  • Changing market protocol fees (max 10%)
  • Approving new marketplace adapters
  • Unpausing markets after an emergency
Guardian Circuit Breaker Instant

Emergency pause powers designed for rapid incident response:

  • Guardian can pause sales immediately
  • Guardian cannot unpause (requires 48h delay)
  • Cannot transfer user NFTs or seize funds
  • Sellers can still cancel their listings while paused
Immutable Guarantees Permanent

Invariants that neither admins, timelocks, nor hackers can change:

  • The 100,000 USDC founding floor can never decrease
  • NFTs cannot be burned or arbitrarily seized
  • No funds can be drained from the market (zero balance)
  • The 48-hour timelock delay can never be shortened
